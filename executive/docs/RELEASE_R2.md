# OSMANX Retail Intelligence — Executive R2 / ATELIER

**Дата:** 08.11.2026. **Статус:** автономная рабочая демонстрация на синтетических данных, не боевой SaaS. Основной FastAPI/SQLite R0.7 не заменён и не модифицирован.

## Пять инженерных блоков

1. **Cinematic ATELIER UI.** Переработан экран собственника: полноразмерная редакционная композиция, выборочный визуальный референс из ранее созданного материала, интерактивные кнопки, ограниченные акценты тёплого золота, мобильная вёрстка; 250-пиксельная постоянная панель заменена скрываемым меню.
2. **Executive Demo.** Работают пять сцен с ручным и автоматическим переходом за 5+6+7+7+5 секунд, видимое разделение «Факт / Оценка / Гипотеза / Прогноз», воронка и связанные чеки. Полоса автопоказа теперь отражает фактические секунды, а не пять одинаковых отрезков. Поддерживается клавиатура, включая стрелки и пробел.
3. **Учёт, аналитика и сценарии.** Детерминированный слой включает 300 моделей, 3 филиала, 90 дней и 3 состояния сети. Действуют фильтры периода, филиала, категории, размера и модели; KPI и десять модулей рассчитываются из событий. Для альтернативного сценария заголовок воронки адаптируется, а не сохраняет ошибочные «60».
4. **Финансовая проверка решения.** Пилот перемещения 3 единиц размера L показывает ожидаемую валовую прибыль с вероятностью, логистикой и неопределённостью. Нажатие «Проверить расчёт» открывает проверяемый итог: это НЕ проведение документа склада и НЕ реальный экономический эффект. Изменение предпосылок сбрасывает прежний итог проверки.
5. **Диагностика и выпуск.** Сохранены семь вопросов, индивидуальные три направления проверки, финансовый калькулятор, режим переговоров, локальный PDF, полный офлайн HTML. Добавлены регрессионные тесты на изменения R2.

## Воспроизводимый контроль

```
npm test
python3 scripts/build_standalone.py
node --check src/app.mjs
node --check build_check.js
```

**30/30 автоматических тестов** прошли в среде сборки на Node 22.

Встроенный Chromium этой среды запрещает открывать все URL управляемой политикой `URLBlocklist: ["*"]`; поэтому нельзя заявлять, что проверены настоящие скриншоты на 390/768/1440/1920 px. `scripts/browser_smoke.py` подготовлен для запуска в CI или на машине без этой политики. Реальный visual regression gate обязателен перед публичной рекламой и коммерческим пилотом.

## Маркировка и границы

- Все данные демонстрационные; 1С, POS, складские системы, платёжные операции и фактическое оборудование не подключены.
- 7 связанных покупок по 8 900 ₽ и себестоимости 4 900 ₽ показывают валовую прибыль **28 000 ₽ по этим чекам**, но не доказанный прирост прибыли от системы.
- В клиентском приложении нет сервера с авторизацией и разграничением организаций; ответы хранятся локально в браузере.
- Идентификаторы покупателей в синтетическом наборе вымышлены. Ни биометрия, ни скрытое отслеживание людей не используются.

## Запуск

Без установки: откройте `OSMANX_EXECUTIVE_OFFLINE.html` в браузере. Для исходников `python3 -m http.server 4173 --bind 127.0.0.1` и `http://127.0.0.1:4173/`.

Для существующего FastAPI проекта можно разместить автономный файл как `frontend/executive.html` (доступ по `/static/executive.html` на локальном сервере). Публичный деплой FastAPI demo-mode запрещён до отдельной проверки безопасности.
