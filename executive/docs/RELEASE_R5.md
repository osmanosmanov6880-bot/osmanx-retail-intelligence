# OSMANX Retail Intelligence · ATELIER R5

**2026-11-08** · Исполнение в изолированной Executive-ветке. **Только синтетические данные** в основной аналитике, реальная 1С/POS/склады **не подключены**.

R5 добавляет пять полных рабочих маршрутов поверх R4 без изменения Python/FastAPI/SQLite backend. Работает как статический сайт или один автономный HTML. Интерфейс — quiet luxury: тёмный графит, тёплая типографика, минимальная насыщенность и аккуратный доступ к источникам.

## Пять модулей

### 01 / LOCAL DATA CONTRACT — `#data-room`

- Пользователь выбирает локальный CSV файл или вставляет текст: **продажи**, **возвраты**, **остатки**.
- Парсер поддерживает UTF-8 BOM, `;`/`,` и кавычки, переносы строк в полях и escaped quotes; ограничение файла 1,2 МБ и 1500 строк.
- Проверка обязательных колонок, уникальности ID, даты, филиала, SKU, размера, чисел, целых количеств и ссылок `return.saleId → sale.id`.
- Возвраты проверяются **только против отдельно загруженных и уже проверенных чеков**, без связывания с синтетическими POS-чеками.
- Проверка атомарная: при любой ошибке подтверждение пакета блокируется. Просмотр ошибок показывает строку и её ID.
- Можно сохранить проверенный пакет **только в оперативной памяти вкладки** и скачать нормализованный CSV с защитой от запуска формул в таблицах.
- Никаких запросов к внешним API. Импортированный CSV **никогда не смешивается** с демонстрационным аналитическим датасетом и не сохраняется в `localStorage`.

### 02 / RETENTION EVIDENCE — `#cohort-lab`

- Когорты участников синтетической программы лояльности по неделе **первой наблюдавшейся в выбранном окне** невозвращённой покупки.
- Настраиваемое число недель и минимальная выборка, еженедельная матрица повторных покупок (по уникальным участникам).
- Незавершённые недели отмечены «—» (не подменяются нулевой возвращаемостью).
- Чеки после возвратов (вплоть до конца выбранного окна) исключаются из положительного события.
- Выбор когорты показывает примеры ID, честное ограничение «первая в окне ≠ первая за всё время», экспорт CSV и запись гипотезы в журнал.
- Здесь нет причинной модели удержания или доказанного финансового эффекта.

### 03 / FUTURE COLLECTION — `#collection-lab`

- Для отдельного **филиала, SKU и размера** собираются неудовлетворённые запросы, активные предзаказы, наличие оплаченных задатков, слабые предпочтения, продажи и возвраты.
- Цвет ограничен демонстрационным «графит»: остальной остаток не выдается за подходящую вещь. Требуется физическая и цветовая сверка.
- План подбирает возможные единицы в пределах бюджета и максимального количества, не расходуя бюджет дважды.
- Настраиваются бюджет, лимит единиц, минимальный запас, срок поставки, сезонный коэффициент и категория.
- Стоимость сценария = Σ(единицы × себестоимость SKU); **не обещание будущей выручки**.
- Выгрузка CSV с IDs и сохранение ограниченной задачи на проверку в журнал. Реальный заказ поставщику не отправляется.

### 04 / SERVICE RESPONSE — `#service-lab`

- По QR-запросам вычисляются p50/p90 времени ответа, доля превышений настраиваемого SLA, доля закрытых обращений, достаточность выборки.
- По примерочным показываются только **озвученные причины** и отдельно неизвестные; неизвестные причины не додумываются.
- Анализ по сети и по каждому филиалу, с примерами событий, CSV и постановкой задачи в журнал.
- Метрики описательные: задержка ответа не равна доказанному упущенному чеку.

### 05 / BRANCH BENCHMARK — `#branch-lab`

- Сопоставление трёх магазинов на **одних и тех же датах**.
- Переключаемые метрики: валовая прибыль, валовая маржа, конверсия входов, запросы без покупки на 100 входов и p90 ожидания ответа.
- Контроль знаменателя: конверсия по фильтру конкретного товара не подменяется посещениями всего магазина.
- Выбор магазина раскрывает исходные IDs, выручку и валовую прибыль, связанную операционную информацию.
- Переход в кабинет выбранного филиала и задача на проверку в журнал; CSV и **реальный одностраничный PDF**, сформированные локально без облака.
- Различия филиалов могут быть связаны с локацией/ассортиментом/потоком; причинность **не установлена**.

## Финансовые и этические ограничения

- Все продажи, посетители, запросы и остатки в основном приложении — синтетические. Семь связанных чеков с валовой прибылью **28 000 ₽** не доказывают дополнительную прибыль от системы.
- Результаты загрузки CSV нельзя использовать как интеграцию с 1С; это **локальная предварительная проверка контракта**, а не синхронизация.
- Явного согласия на персональную аналитику в реальном бизнесе может не быть. Демо использует псевдонимизированные синтетические события.
- План закупки — сценарий, не реальный заказ; учётный остаток не гарантирует физическую доступность.
- PDF/CSV — демонстрационные файлы, без цифровой подписи, не подтверждающие реальную финансовую отчётность.

## Запуск

```bash
cd executive
python3 -m http.server 4173 --bind 127.0.0.1
# Открыть http://127.0.0.1:4173/index.html
```

Либо просто открыть `executive/OSMANX_EXECUTIVE_OFFLINE.html` в браузере. На телефоне файловый просмотрщик иногда блокирует локальный JavaScript: используйте полноценный браузер или локальный HTTP-сервер. Платные сервисы и регистрация не требуются.

## Приёмка

```bash
cd executive
node --test tests/*.test.mjs
python3 scripts/build_standalone.py
node --check build_check.js
python3 scripts/browser_smoke.py
python3 scripts/r3_browser_smoke.py
python3 scripts/r4_browser_smoke.py
python3 scripts/r5_browser_smoke.py
```

Новые Node-тесты покрывают контракт CSV (включая XSS/CSV formula injection, структурные ошибки и orphan-returns), учёт возвратов в когортах, ограничения бюджета закупки, KPI сервиса и идентичность периодов филиалов. Браузерный CI проверяет пять страниц на 390/768/1440/1920 px и реальное взаимодействие с кнопками, полями, файлами и PDF. В некоторых локальных средах Chromium блокирует `127.0.0.1`; тогда независимый GitHub Actions остаётся источником браузерной приёмки.

## Что ещё не сделано

Продакшен-интеграция 1С, API событий, шифрованное хранилище импортированных бизнес-данных, tenant/RBAC, реальный ETL/очереди и публичный SaaS. R5 **не изменяет** backend и не публикует сервер деморежима.
