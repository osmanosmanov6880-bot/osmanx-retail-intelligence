# R5 · CSV Contract / Local Preview Only

## Важные правила

Данные загружаются только в память браузера, затем проходят строгую проверку. При любой ошибке строк весь пакет отклоняется. Это не импорт в действующую систему и не обмен с 1С. Данные не объединяются с синтетическими показателями. Выбор CSV не отправляет его на сервер. Не загружайте ФИО, телефоны, номера карт или иную персональную информацию.

UTF-8, разделители `;` или `,`, кавычки, первая строка — точные имена полей. Можно использовать кнопку «Пример» в каждом типе.

### sales

```csv
id;date;storeId;modelId;size;paidPrice;cost
sale-example;2026-11-08;s1;JKT-AURA;L;8900;4900
```

### returns

Сначала отдельно проверьте и подтвердите файл `sales` в том же сеансе вкладки. `saleId` должен указывать на один из этих импортированных чеков, а не на синтетический чек.

```csv
id;date;storeId;saleId;modelId;size;refundedPrice;reversedCost
return-example;2026-11-08;s1;sale-example;JKT-AURA;L;8900;4900
```

### stock

```csv
id;asOf;storeId;modelId;size;color;quantity
stock-example;2026-11-08;s1;JKT-AURA;L;Графит;3
```

`storeId` принимает только `s1`,`s2`,`s3`; `modelId` — существующий SKU демонстрационного справочника 300 моделей. Для настоящего импорта необходимо отдельно сопоставить внешние коды товара, размеры, модели и организации; таких интеграций пока нет. Цена/себестоимость — числа в рублях, количество — неотрицательное целое. Даты календарные `YYYY-MM-DD`.

## Безопасность

- CSV, который будет открыт в Excel/Sheets, всегда экранирует опасные начальные символы `= + @ -`.
- Дубликаты событий, порванные кавычки, неизвестные SKU и ссылки на отсутствующие чеки отклоняются.
- Проверенный пакет не попадает в `localStorage`, GitHub, 1С или синтетический финансовый движок.
- Этап «подтвердить» сохраняет набор только в памяти текущей вкладки; после перезагрузки он исчезает.
- Для настоящей компании потребуются контроль доступа, согласование правовых оснований, серверная повторная валидация и защищённый журнал импорта.
