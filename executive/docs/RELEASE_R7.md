# ATELIER R7 — Decision Assurance Suite

**Дата демосреза:** 8 ноября 2026 г. Статус: локальная демонстрация, не публичный B2B SaaS и не действующая интеграция с 1С.

## Пять реализованных блоков

1. **Evidence Assurance Gate.** Сопоставляет синтетические запросы, чеки, возвраты и остатки. Показывает пять проверок: уникальность ID, корректность связей возвратов, соответствие запросов связанным покупкам, актуальность снимка остатков и минимальная выборка. При ошибках выводится блокировка *проверки финансовой гипотезы*, а не вымышленная подтверждённая прибыль. Проверка является внутренним контролем согласованности, не внешним аудитом и не доказательством причинности. Поддерживает контроль порогов, CSV и назначение задачи.
2. **Network Rebalance Simulator.** Детальный расчёт текущих сценариев межфилиальных перемещений по SKU/размеру/цвету/филиалу, зафиксированному неудовлетворённому спросу, резерву источника и собственным логистическим расходам. Один и тот же доступный остаток и запрос не распределяются дважды. При наличии положительного учётного остатка в филиале назначения предлагается сначала физическая сверка. Нулевой/отрицательный прогноз не рекомендуется. Только моделирование: перемещение, резервирование и отправка уведомлений **не выполняются**.
3. **Capital Discipline.** Ограниченная бюджетом 0/1 оптимизация до 12 независимых кандидатов с проверкой стоимости логистики, отдельной стоимостью пилотной проверки, количеством одновременных задач и дисконтом предположений. Показатель — **консервативный сценарный нетто-эффект**, не наблюдаемая прибыль. Выбор можно экспортировать и поставить на ручное утверждение.
4. **Privacy Lab.** Модель обработки только добровольных запросов и предзаказов, учитывающая срок хранения и согласие. Исключённые события остаются в синтетическом исходном наборе, так как это предпросмотр политики, **а не удаление реальных данных**. Экспортируются только агрегаты по дате, филиалу и типу события. Локальный журнал сохраняет дату, параметры и счётчики без имён, телефонов и индивидуальных идентификаторов; FNV-подобная проверочная сумма не является криптографической подписью.
5. **Executive Evidence Brief.** Пять заключений с меткой `ФАКТ ДЕМО / ПРОГНОЗ / ГИПОТЕЗА / ТРЕБУЕТ ПРОВЕРКИ`, исходными ID, формулами и ограничениями. Экспортируются CSV и настоящий одностраничный PDF A4 (Canvas + встроенный PDF writer). Можно создать задачу для управляющего. Отчёт не является финансовой гарантией.

## Финансовые границы

- Продажа/возврат: факты только **внутри синтетического набора**; валовая прибыль не равна чистой прибыли.
- Снимок наличия от `2026-11-08`: можно моделировать лишь **текущую** возможность перемещения, но нельзя делать вывод о наличии в день прошлой заявки.
- `сценарная валовая прибыль = количество × (цена − себестоимость) × вероятность`, `сценарный нетто-эффект = сценарная валовая прибыль − фиксированные затраты − переменные затраты`.
- Бюджетный модуль считает `консервативный эффект = сценарная валовая прибыль × коэффициент осторожности − стоимость маршрута − цена проверки`. Коэффициент — ручное предположение, не статистическая уверенность.
- Для фактического прироста необходимы подтверждение связей, контрольные группы и сопоставимые периоды. Источники в демо не доказывают, что продажа не состоялась бы без OSMANX.
- Задачи R7 пишутся только в локальный журнал R6; физическое движение складских единиц, отправка сообщений, подключение реальных касс и реальное удаление данных отсутствуют.

## Запуск и проверка

```bash
cd executive
npm test
python3 scripts/build_standalone.py
node --check build_check.js
python3 scripts/r7_browser_smoke.py  # если доступен Chromium Playwright
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4173/` для модульного режима либо `executive/OSMANX_EXECUTIVE_OFFLINE.html` для автономного показа без сети. Встроенный IndexedDB не используется; браузерный `localStorage` хранит только локальные сценарии и журнал демозадач. CSV-выгрузки не заменяют данные 1С.

### Полный автоматизированный контроль

- Все тесты R1–R6 сохранены и запускаются через `node --test tests/*.test.mjs`.
- R7: `tests/r7_core.test.mjs` проверяет ссылки, остатки, бюджет, согласия, неизменность исходных данных, статус выводов; `tests/r7_routes.test.mjs` проверяет интеграцию интерфейса, маршруты и сборку.
- GitHub Actions запускает Chromium на 390, 768, 1440 и 1920 px, проверяет пять новых маршрутов, действия, PDF/CSV и отсутствие JavaScript-ошибок.
- Публичное развёртывание в этом релизе **не выполняется**. Приёмка не означает готовность к размещению открытого production-сервера.
