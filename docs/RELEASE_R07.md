# OSMANX Retail Intelligence R0.7 — Store Operations

Статус: код и тесты подготовлены для GitHub. **Публичное развёртывание отложено по требованию владельца.**

## Пять полноценных модулей

1. **Инвентаризация.** POST `/api/admin/r07/counts` создаёт транзакционный снимок позиций с исходным количеством, источником и отметкой изменения. POST `/counts/{id}/apply` проверяет устаревание, не допускает корректировки ниже действующих резервов, применяет изменения атомарно и создаёт отдельный журнал `stock_adjustments_r07`. Повтор применения не удваивает остатки; отмена возможна только до применения. В работе используются только существующие SKU филиала. Для новых SKU есть прежний импорт.
2. **Межфилиальные перемещения.** Создание уникального документа, отправка (списание со склада-источника при повторной проверке свободного остатка), приёмка в филиале назначения (увеличение или создание позиции), запрет несовпадения характеристик SKU, защита от двойной отправки/приёмки и транзакционный журнал. Перемещение не считается продажей.
3. **Помощь покупателю без видеослежения.** Ответственный создаёт точку с секретной ссылкой `/assist/<token>`; сервер хранит только SHA-256 ключа, публичная страница не запрашивает имя/телефон. Покупатель выбирает тип обращения, сотрудник отмечает принятие и завершение; очередь и время реакции сохраняются. Ограничение открытых запросов и частоты защищает от простого спама. Ссылка показывается один раз и может быть отключена.
4. **Сравнение торговых зон.** Задание А/Б периодов для конкретной зоны и двух вариантов выкладки, подсчёт нормированных на день событий реального датчика, контроль источников и минимального объёма событий. Результат носит описательный характер и не доказывает причинность или рост прибыли.
5. **Кабинет собственника.** Последние 14 дней: посещаемость и её источники, подтверждённые чеки, конверсия как ориентир, детализация валовой маржи только по разнесённым SKU, активные запросы, складские расхождения, перемещения в пути, запросы на помощь, эксперименты и приоритеты. CSV с BOM и защитой от формул. Данные разделяются по организации/филиалу.

## Доступ и разделение данных

- Новые `/api/admin/r07/*` защищены прежней сессией OSMANX и проверкой организации/филиала. Записывать изменения могут `owner` и `manager`; `analyst` и `viewer` имеют доступ только для чтения назначенных филиалов.
- Публичный `POST /api/assist/{token}` не даёт административного доступа, действует только для включённой точки, поддерживает идемпотентность и ограничения частоты.
- Для склада используется SQLite `BEGIN IMMEDIATE` + проверки остатков, включая уже удержанные резервы действующей R0.5.
- Новые таблицы создаются идемпотентной миграцией при старте. Старые продажи, чеки, товары и пользовательские данные не удаляются.
- Все подтверждённые изменения фиксируются в журнале аудита действий.

## Запуск и проверки

```bash
pip install -r requirements.txt pytest httpx playwright
OSMANX_DEMO_MODE=1 python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
python -m pytest tests -q
python scripts/r07_browser_smoke.py
```

Интерфейсы: `/static/operations.html` — пять разделов; `/static/workflows.html` — R0.6; `/` — прежний кабинет; `/assist/<token>` — публичная кнопка помощи внутри магазина. Тесты Chromium работают через TestClient без публичного сервера. Для настоящих QR-кодов и устройств понадобится развёртывание с HTTPS; оно **не выполнено**.

## Важные ограничения

- Источники посещаемости могут пересекаться: отчёт выводит предупреждение, но не определяет по камере намерение покупателя.
- Нет автоматической интеграции с 1С, POS-оборудованием, физическими датчиками или мессенджерами без подключения конкретного провайдера.
- QR-ссылка — секрет доступа к точке; её необходимо разместить только на доверенном носителе. Для промышленного использования нужны дополнительные сетевые лимиты, централизованное наблюдение и политика безопасности.
- Цена, валовая маржа и сравнение зон не равны доказанной дополнительной чистой прибыли.
- В пользовательском интерфейсе нет распознавания лиц и персонального отслеживания покупателей.
